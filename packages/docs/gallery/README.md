# 图例文档

图例文档解释竖式页面中可见图元的命名、语义和教学用途。阅读时先看总览，再按需要查看命名图谱；它与宏说明、技术实现分开维护，不把视觉命名反向写入计算器算法。

## 阅读入口

- [竖式元素命名图谱](./命名图谱.md)：按运算查看图元名称、语义和主应用演示入口。

## 竖式元素命名图谱

主应用提供加法、减法、乘法、除法和短除法的交互式命名图谱。图谱以真实 `GridScene` 作为输入，适合核对布局层输出和渲染器输入字段。

| 运算 | 主应用入口 |
| --- | --- |
| 加法 | `/addition-elements` |
| 减法 | `/subtraction-elements` |
| 乘法 | `/multiplication-elements` |
| 除法 | `/division-elements` |
| 短除法 | `/short-division-elements` |

命名图谱页面由主应用和文档站分别提供交互展示；本文档只定义分类、命名、语义 token 和必要的文字说明，避免维护两套图例数据。计算过程、`GridScene` JSON 和渲染器字段不在图例页展示；需要了解实现细节时请阅读对应的计算规则、布局规则和网格架构文档。
