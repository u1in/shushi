# 图例文档

图例文档解释竖式页面中可见图元的命名、语义和教学用途。阅读时先看总览，再按需要查看命名图谱；它与宏说明、技术实现分开维护，不把视觉命名反向写入计算器算法。

## 阅读入口

- [加法竖式元素命名图谱](./加法.md)：按运算查看图元名称、语义和交互式图例。

## 竖式元素命名图谱

VuePress 文档站提供加法、减法、乘法、除法和短除法的交互式命名图谱。图谱以真实 `GridScene` 作为输入，适合核对布局层输出和渲染器输入字段。

| 运算   | VuePress 文档入口 |
| ------ | ----------------- |
| 加法   | `/gallery/加法`   |
| 减法   | `/gallery/减法`   |
| 乘法   | `/gallery/乘法`   |
| 除法   | `/gallery/除法`   |
| 短除法 | `/gallery/短除法` |

命名图谱页面统一由 VuePress 文档站提供交互展示；本文档只定义分类、命名、语义 token 和必要的文字说明，避免维护两套图例数据。计算过程、`GridScene` JSON 和渲染器字段不在图例页展示；需要了解实现细节时请阅读对应的计算规则、布局规则和网格架构文档。
