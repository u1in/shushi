# 宏说明

宏命令文档是面向使用者的渐进式入口，按“先跑通、再理解结构、最后查命令”的顺序组织。它不混入计算器算法或 Vue 应用的工程细节。

## 推荐阅读顺序

1. [入门与快速开始](./入门与快速开始.md)：先理解宏语言解决什么问题，再完成第一次编译和渲染。
2. [基础宏命令](./基础宏命令.md)：学习 GRID、ROW、CELL、LINE 等结构命令。
3. [定位宏命令](./定位宏命令.md)：掌握九宫格位置、字号和右边界文字。
4. [符号与边框](./符号与边框.md)：学习 DOT、BRACKET 和单元格边框命令。
5. [语法糖](./语法糖.md)：在源码已经正确后，再压缩写法。
6. [实践与排错](./实践与排错.md)：用完整算式和常见错误巩固前面的规则。

[网格宏语言规则](./网格宏语言规则.md)保留为语义边界和编译约束的总览，适合查阅而不是作为第一篇阅读材料。
