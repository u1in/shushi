# 竖式布局规则

本目录集中维护各运算的宏排版规则。布局实现位于 `packages/layout/src`，只负责把计算过程填写为人类可编辑的宏字符串；唯一的 `GridScene` 生成入口是 `@u1in/shushi-macro` 的 `compileMacro`。

所有自动竖式都必须满足“复制生成源码到宏调试的宏源码框可复刻相同结果”的项目原则。布局模块不得直接组装 `GridScene`。

所有运算的播放共享“计算器前缀快照”契约：设置 `visibleStepCount` 后，布局只能截取 `computation.calculationSteps` 的前缀。每项快照由计算器生成，只包含原始输入、此前步骤和当前已完成的补零、数位、进位、借位、部分积、商位或余数；布局不得另造播放事件、读取未来结果或预留未来网格宽度。
