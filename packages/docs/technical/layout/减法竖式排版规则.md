# 减法竖式排版规则

> 版本：V2.0
> 适用范围：`SubtractionComputation → 减法宏字符串 → compileMacro → GridScene → DOM / SVG` 的减法竖式

减法算法和借位字段见 [`减法计算规则.md`](../calculator/减法计算规则.md)。本文件只定义排版；连续借位只能在计算层推导。

## 1. 宏源码与行

减法布局器导出 `createSubtractionMacroSource`，由 `GRID`、`ROW`、`CELL`、`MTD` 和 `LINE` 写出可编辑源码；兼容的 `createSubtractionGridScene` 不含直接网格组装逻辑，只编译该源码。

- 最左为宏中的一个完整减号单元格，之后为普通数字列；被减数、减数和差均以个位右对齐。
- 行顺序为：原始工作被减数行、减数行、差行。
- 被减数行始终显示 `workingMinuendDigits` 的原始数字；`steps.minuendDisplay` 是中间计算值，只保留在计算结果中，不替换竖式主行。
- `showBorrowSteps` 开启时，每个需要借位的高位数字上方显示小号 `·`；关闭时隐藏这些借位提示，但不改变被减数主行。
- 每个 `borrowOut = 1` 的步骤，在左侧高一位的同一单元格写入 `MTD` 借位点；其字号和锚定完全由公共宏命令定义，不使用 API 专属边中点坐标。
- 原始被减数小于减数时，计算层输出大数减小数的绝对值过程，差行运算符列额外显示负号；原始表达式仍由页面结果文字说明。

## 2. 横线与 token

横线固定覆盖减号列和数字区域；减法不提供横线范围开关。

| token                        | 用途                       |
| ---------------------------- | -------------------------- |
| `subtraction.minuend`        | 竖式主行中的工作被减数     |
| `subtraction.borrow`         | 被借位数字上方的小号借位点 |
| `subtraction.subtrahend`     | 减数                       |
| `subtraction.operator`       | 减号                       |
| `subtraction.difference-bar` | 减法横线                   |
| `subtraction.difference`     | 差的绝对值                 |
| `subtraction.negative-sign`  | 负数结果的符号             |

DOM/CSS 与 SVG 都只渲染 token、轨道和元素；不包含“遇到 0 继续借位”等运算判断。

## 3. 示例：502 − 137

```text
      · ·
      5 0 2
−     1 3 7
────────────
      3 6 5
```

`12` 占个位的同一数位单元格，表示借来的一个十，不代表新开十位列。

## 4. 步骤检查

`SubtractionRenderSettings.visibleStepCount` 未设置时显示完整差；设置为 `k` 时按个位到高位显示前 `k` 个差位和借位提示。被减数主行仍保持完整，避免检查过程时丢失原始输入；负号只在完整结果视图中显示。
