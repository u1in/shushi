## 推荐阅读路径

1. [计算规则](./calculator/)：先知道单项及组合运算输出哪些过程数据。
2. [竖式布局规则](./layout/)：再了解过程如何变成可编辑宏源码和 `GridScene`。
3. [网格架构](./grid/网格架构.md)：最后理解轨道、单元格、元素、对齐和渲染边界。
