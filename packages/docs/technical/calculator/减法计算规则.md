# 减法计算规则

> 版本：V2.0
> 适用范围：本项目的非负十进制减法器、小数位对齐、借位过程和负结果表示

本文件定义 `packages/calculators/src/subtraction.ts` 的计算行为。竖式编排见 [`减法竖式排版规则.md`](../layout/减法竖式排版规则.md)。

## 1. 输入与结果

- 被减数、减数均可为十进制非负数；空值、负数、空白、缺少整数或小数部分的点号及其他格式必须报错。
- 输入先移除整数部分前导 `0`，零规范化为 `"0"`；小数末尾的 `0` 保留以表达位值。完整数字始终使用字符串存储，不能转成 `Number` 或 `BigInt`。
- 计算前取两数中最长的小数位数 `decimalPlaces`，并向较短的小数右补 `0` 后去掉小数点；例如 `8.7 − 0.89` 按 `870 − 089` 计算，最终恢复为 `7.81`。补零、借位列、结果小数点和必要的前导零都由计算器按发生顺序写入 `calculationSteps`，布局不会自行补出事件。
- 当被减数不小于减数，直接计算 `被减数 − 减数`。当被减数小于减数，`resultText` 前加 `-`，并用“大数减小数”导出绝对值的借位过程。
- `minuendText`、`subtrahendText` 保留规范化后的原始输入；`minuendDigits`、`subtrahendDigits` 是按公共小数位右补零后的去点过程数字。`workingMinuendDigits`、`workingSubtrahendDigits` 是实际执行逐位减法的两个数，`working*Text` 在相同位置恢复小数点。

## 2. 逐位借位算法

从个位向高位计算，令 `borrow = 0`：

```text
workingDigit = 当前被减数位 - borrow

若 workingDigit < 当前减数位：
  minuendDisplay = workingDigit + 10
  borrow = 1
否则：
  minuendDisplay = workingDigit
  borrow = 0

resultDigit = minuendDisplay - 当前减数位
```

- 缺失的减数高位按 `0` 处理。
- `borrow` 是低位向当前位借走的 `1`，因此当前位先减去它；若当前位为 `0`，连续借位后 `workingDigit` 可为 `-1`，再借一位便显示为 `9`。
- 每列导出 `SubtractionColumnStep`。`minuendDisplay` 是该列真正参与相减的中间值，范围通常为 `0…18`，供计算步骤保留完整借位信息。
- 最后去除差的前导 `0`，至少保留一位；中间 `0` 和个位 `0` 必须保留。恢复小数点时，若数字位数不够则在左侧补 `0`，因此 `51` 配合两位小数输出为 `0.51`。

## 3. 示例：502 − 137

```text
个位：2 不够减 7，向十位借 1；十位是 0，继续向百位借。
百位：5 被借后为 4。
十位：10 再借给个位后为 9。
个位：得到 12。
结果：12 − 7 = 5，9 − 3 = 6，4 − 1 = 3，即 365。
```

`steps` 从个位到百位导出的 `minuendDisplay` 依次为 `"12"`、`"9"`、`"4"`；这些值属于中间计算步骤，竖式主行仍显示 `5、0、2`。

## 4. 小数示例：0.80 − 0.29

最长小数位数为两位，因此先按 `080 − 029` 逐列相减：

```text
百分位：0 不够减 9，借位后得到 1。
十分位：7 − 2 = 5。
整数位：0 − 0 = 0。
结果：0.51。
```

`differenceDigits` 保持为 `"51"`，`resultText` 为 `"0.51"`；前导零只在格式化最终十进制文本时恢复，不把它伪造成额外的借位列。

## 5. 特殊情况和不变量

- 本位够减绝不借位；借来 `1` 在本位表示 `10`。
- `1000 − 1` 必须经过连续借位，差为 `999`。
- 相同数字相减结果为 `0`。
- `12 − 35` 的 `resultText` 为 `"-23"`；其工作过程为 `35 − 12`，并标记 `isNegative = true`。
- 对任意输入数学值 `a`、`b`，`resultText` 表示 `a − b`；字符串算法不受 JavaScript 安全整数范围限制。

## 6. 输出契约

```ts
{
  minuendDigits: string,
  subtrahendDigits: string,
  minuendText: string,
  subtrahendText: string,
  minuendDecimalPlaces: number,
  subtrahendDecimalPlaces: number,
  decimalPlaces: number,
  workingMinuendDigits: string,
  workingSubtrahendDigits: string,
  workingMinuendText: string,
  workingSubtrahendText: string,
  differenceDigits: string,
  resultText: string,
  isNegative: boolean,
  steps: SubtractionColumnStep[],
  calculationSteps: CalculationStepSnapshot[],
}
```
