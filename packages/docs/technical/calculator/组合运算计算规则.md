# 组合运算计算规则

`computeCompositeArithmetic(expression)` 将由 `+`、`-`、`×`（也接受 `*`、`x`）连接的非负十进制数字符串按**书写顺序从左到右**执行。加、减、乘均支持小数；小数减法仍委托 `computeSubtraction` 完成位数对齐、借位和结果小数点步骤。它不使用通常的乘法优先级：`125 + 75 - 20 × 3` 表示 `((125 + 75) - 20) × 3`。

## 单项规则复用

每一个组合步骤只委托给一个既有计算器：

- `+` 使用 `computeAddition`，保留逐列加数、进位和和；
- `-` 使用 `computeSubtraction`，保留逐列借位和差；
- `×` 使用 `computeMultiplication`，保留逐位部分积和列加法。

因此返回的 `steps` 是带 `operator` 判别字段的联合类型；`calculationSteps` 会按书写顺序展平每个已完成子运算的快照，并在后续子运算前写入当前运算符和第二操作数的引入快照。每项不包含未来子运算结果；布局层不得再次计算进位、借位或部分积。

## 乘法与边界

组合中的乘法固定传入 `useTrailingZeroShortcut: false` 与 `preserveOperandOrder: true`：不使用十倍数快捷计算，也不为排版交换两个操作数。

输入和每一步开始时都必须是非负十进制数。减法可以作为最后一步得到负数；若负数中间结果还要继续组合，函数会抛出错误。此限制保证后续单项竖式仍完全遵守现有非负数教学规则。
