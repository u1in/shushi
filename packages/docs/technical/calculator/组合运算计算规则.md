# 组合运算计算规则

`computeCompositeArithmetic(expression)` 将由 `+`、`-`、`×`（也接受 `*`、`x`）连接的非负十进制数字符串按**书写顺序从左到右**执行。加法和乘法支持小数；任一步含小数的减法会报错。它不使用通常的乘法优先级：`125 + 75 - 20 × 3` 表示 `((125 + 75) - 20) × 3`。

## 单项规则复用

每一个组合步骤只委托给一个既有计算器：

- `+` 使用 `computeAddition`，保留逐列加数、进位和和；
- `-` 使用 `computeSubtraction`，保留逐列借位和差；
- `×` 使用 `computeMultiplication`，保留逐位部分积和列加法。

因此返回的 `steps` 是带 `operator` 判别字段的联合类型；布局层不得再次计算进位、借位或部分积。

## 乘法与边界

组合中的乘法固定传入 `useTrailingZeroShortcut: false` 与 `preserveOperandOrder: true`：不使用十倍数快捷计算，也不为排版交换两个操作数。

输入和每一步开始时都必须是非负整数。减法可以作为最后一步得到负数；若负数中间结果还要继续组合，函数会抛出错误。此限制保证后续单项竖式仍完全遵守现有非负整数教学规则。
