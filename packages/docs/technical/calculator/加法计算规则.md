# 加法计算规则

> 版本：V1.0  
> 适用范围：本项目的非负十进制加法器、两数加法和连加过程数据

本文件定义 `packages/calculators/src/addition.ts` 的计算行为。竖式编排见 [`加法竖式排版规则.md`](../layout/加法竖式排版规则.md)。

## 1. 输入与结果

- `computeAddition` 接收两个或多个十进制非负数；也可传入单一数组以表达连加。
- 每个输入可带一个小数点；空值、负数、空白、缺少整数或小数部分的点号及其他格式均报错。整数部分移除前导 `0`，小数末尾的 `0` 保留以维护位值。
- 所有完整整数均为字符串，不能转换为 `Number`、`BigInt` 或其他大数类型；仅单个数字和一列合计可短暂转为 `Number`。
- 计算前收集最长小数位数，将每个加数右补 `0` 后按整数逐列计算；`sumDigits` 保存去点后的过程数字，`sumText` 在对应位置恢复小数点。`addendDecimalPlaces` 保留补零前的小数位数，供布局层把每一个补入的 `0` 编排为独立教学步骤。

## 2. 逐位算法

同一数位右对齐，从个位向高位（从右至左）计算。令 `carry = 0`，每一列执行：

```text
total       = 所有加数的本列数字之和 + carry
resultDigit = total % 10
carry       = floor(total / 10)
```

- 缺失的高位按 `0` 参与计算。
- `resultDigit` 从右向左组成结果。
- 最高位相加后若仍有进位，继续新建一列写入该进位；这保证如 `95 + 15 = 110` 的百位 `1` 不丢失。
- 每列输出一项 `AdditionColumnStep`，`columnFromRight` 从个位的 `0` 开始，记录每个加数的本列数字、进位输入、合计、结果数字和进位输出。

## 3. 示例：356 + 278

```text
个位：6 + 8 = 14，写 4，进 1
十位：5 + 7 + 1 = 13，写 3，进 1
百位：3 + 2 + 1 = 6，写 6
结果：634
```

对应输出的 `addendDigits` 为 `["356", "278"]`，`sumDigits` / `sumText` 均为 `"634"`。`steps` 从个位开始依次记录合计 `14`、`13`、`6`。

例如 `1.2 + 3.04` 会以公共两位小数计算 `120 + 304`；过程 `sumDigits` 为 `"424"`，显示结果 `sumText` 为 `"4.24"`。

## 4. 特殊情况和不变量

- 任何数与 `0` 相加等于原数；连加中的 `0` 也不可省略过程输入。
- 连加遵循同一列一次合计全部加数的规则，例如 `5 + 8 + 9 = 22` 在个位产生 `carryOut = 2`。
- 对任意数学值为 `a₁ … aₙ` 的输入，输出必须满足 `sumDigits = a₁ + … + aₙ`；计算不受 JavaScript 安全整数范围限制。
- 排版坐标、行列号、DOM、CSS 和 SVG 不得出现在本计算结果中。

## 5. 输出契约

```ts
{
  addendDigits: string[],
  addendTexts: string[],
  addendDecimalPlaces: number[],
  decimalPlaces: number,
  sumDigits: string,
  sumText: string,
  steps: AdditionColumnStep[],
}
```

## 6. 验证清单

| 输入             | 期望结果                |
| ---------------- | ----------------------- |
| `356 + 278`      | `634`，个位、十位均进 1 |
| `95 + 15`        | `110`，保留最高位进位   |
| `000 + 0012`     | `12`                    |
| `5 + 8 + 9`      | `22`，支持连加          |
| 超长数字串 + `1` | 不依赖安全整数范围      |
