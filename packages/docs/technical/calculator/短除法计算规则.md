# 短除法计算规则

> 适用范围：`computeShortDivision` 的输入校验、过程数据、终止条件与结果。竖式轨道和视觉规则见 [`短除法竖式排版规则.md`](../layout/短除法竖式排版规则.md)。

## 1. 入口与通用约定

计算器入口为 `computeShortDivision({ mode, values, divisor?, targetBase? })`，仅输出语义化数字字符串和过程行，不输出 DOM、CSS、坐标或 `GridScene`。

| 字段          | 说明                                                                                                              |
| ------------- | ----------------------------------------------------------------------------------------------------------------- |
| `mode`        | `division`（指定除数）、`factorization`（质因数分解）、`commonFactor`（GCD / LCM）或 `baseConversion`（进制转换） |
| `values`      | 输入数数组；指定除数、分解和进制转换使用一个数，公因数模式至少两个正整数                                          |
| `divisor`     | 仅 `division` 使用的正整数除数                                                                                    |
| `targetBase`  | 仅进制转换使用，范围为 2–36，默认 2                                                                               |
| `steps`       | 自上而下的 `ShortDivisionStep[]`，包含本轮 `divisor`、右侧 `dividends`、下一行 `quotients` 和 `remainders`        |
| `finalValues` | 停止时写在底行的数                                                                                                |

质因数试除和公因数试除采用课堂式的逐个候选质数枚举，输入上限为 `1,000,000,000`，以避免大质数令浏览器长时间阻塞；进制转换使用十进制字符串长除法，不受该上限限制。输入中的前导零会规范化；空串、负数、小数和非数字字符均报错。

## 2. 指定除数短除法

1. 输入一个非负被除数和一个正整数除数。
2. 计算器生成一条 `ShortDivisionStep`：左侧为 `divisor`，右侧为被除数，底行写商；`remainder` 保留在结果和步骤中。
3. 此模式不枚举质数，也不自动继续对商试除。

该模式通过 `computeShortDivision({ mode: 'division', values: ['12'], divisor: '2' })` 使用，得到一行“2｜12”，底行是 `6`，结果的 `quotient` 为 `6`、`remainder` 为 `0`。字符串表达式入口不暴露这个低层的一次指定除法；`|48` 用于质因数分解，`|12 28` 用于自动试除求公因数。

## 3. 分解质因数 / 求约数

1. 输入一个正整数，从最小质数开始试除。
2. 每次找到能整除当前商的最小质数，就输出一条过程行，商进入下一轮。
3. 当前商成为质数或 `1` 时停止。最后的质数只写底行，不再额外写一次除数。
4. `primeFactors` 为左侧过程除数加上底行质数；`factorizationText` 按指数合并；`divisorCount` 和 `divisorSum` 分别根据指数公式计算。

例如 60 的过程除数为 `["2", "2", "3"]`，底行是 `5`，`primeFactors` 为 `["2", "2", "3", "5"]`，结果为 `2^2 × 3 × 5`、约数个数 `12`、约数和 `168`。质数 13 没有过程行，底行直接为 13；1 的分解结果为 `1`。

## 4. 求最大公约数 / 最小公倍数

1. 输入至少两个正整数。
2. 找到能同时整除所有当前数的最小公共质因数，记录为一条过程行；所有商进入下一轮。
3. 没有公共质因数时停止，当前各商写入 `finalValues`。
4. 左侧 `divisors` 相乘为 `gcd`；`divisors` 与底行所有 `finalValues` 相乘为 `lcm`。

例如 12、18 依次共同除以 2、3，底行是 2、3，因此 `gcd = 6`，`lcm = 36`。若初始数已经互质，则没有过程行、GCD 为 1，LCM 为所有输入数之积。

## 5. 十进制转其他进制

1. 输入一个非负十进制数字串和目标进制 `b`。
2. 每一轮执行当前数的整数除法 `÷ b`；商写入下一行，余数记录为 `remainders[0]`。
3. 商为 0 时停止，余数数组倒序后为 `remaindersBottomUp`，拼接后为 `convertedText`。

例如 13 转二进制的过程余数自上而下为 `1、0、1、1`，倒序仍为 `1101`。100 转八进制的余数自上而下为 `4、4、1`，结果为 `144`。当输入为 0 时不生成过程行，结果固定为 `0`。

对于 11–36 进制，余数 10–35 使用大写 `A`–`Z`。每轮余数均小于目标进制，商恒为非负整数。

## 6. 验证清单

- 指定除数：2｜12 → 商 6、余数 0；5｜12 → 商 2、余数 2。
- 分解：60 → `2^2 × 3 × 5`，约数个数 12，约数和 168；13 → `13`；1 → `1`。
- 公因数：12、18 → GCD 6、LCM 36；12、28 → GCD 4、LCM 84；8、9 → GCD 1、LCM 72。
- 进制：13₁₀ → 1101₂；100₁₀ → 144₈；0₁₀ → 0₂。
- 异常：分解或公因数的 0 / 负数、少于两个公因数输入、目标进制小于 2 或大于 36 都必须报错。
