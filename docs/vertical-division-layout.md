# 小学除法竖式排版规则

> 版本：V16.0<br>
> 适用范围：`vertical-division-demo` 的坐标、SVG / div + CSS 渲染、线条和交互状态

本文件以 `deepseek_html_20261028_7a4ad6.html` 为规则来源，描述项目当前可切换的 SVG 与 `div + CSS` 视觉实现。整数逐位长除法规则和计算中间过程见 [`division-rules.md`](./division-rules.md)。

## 1. 竖式元素命名

排版层 `src/vertical-division-layout.ts` 将计算过程转换为 `VerticalDivisionRenderModel`；SVG 与 `div + CSS` 渲染器只能消费该模型。以下名称同时是 TypeScript `kind` / `role`、CSS 语义类和文档术语的唯一来源。

| 中文名称 / English name | TypeScript 名称 | CSS 语义类 | 说明 |
| --- | --- | --- | --- |
| 厂圆弧 / Division bracket arc | `divisionBracketArc` | `.division-bracket-arc` | 从左下到右上收笔的厂字弯钩。 |
| 厂横线 / Division bracket top line | `divisionBracketTopLine` | `.division-line--divisionBracketTopLine` | 厂圆弧右上端向右延伸的横线。 |
| 减法线 / Subtraction bar | `subtractionBar` | `.division-line--subtractionBar` | 每次乘积行下方的横线。 |
| 辅助网格横线 / 竖线 / Guide grid horizontal / vertical | `guideGridHorizontal` / `guideGridVertical` | 对应 `.division-line--…` | 仅在开启辅助网格时生成。 |
| 除数 / 被除数 / 商位 / Divisor / Dividend / Quotient | `divisor` / `dividend` / `quotient` | `.division-digit--…` | 各自数字单元格。 |
| 部分被除数 / Partial dividend | `partialDividend` | `.division-digit--partialDividend` | 首轮以外、落在减法线下方的当前部分被除数。 |
| 乘积 / Product | `product` | `.division-digit--product` | 除数与本轮商位的乘积。 |
| 最终余数 / Final remainder | `remainder` | `.division-digit--remainder` | 所有实际减法步骤后的最后一行，包含 `0`。 |
| 补零列 / Appended zero | `appendedZero` | `.division-digit--appendedZero` | 有限小数模式中被除数右侧追加的弱化 `0`。 |
| 小数点 / Decimal point | `decimalPoint` | `.division-decimal-point` | 原被除数末列和首个补零列的边界节点，不占数字格；其 `x` 是已包含被除数区左边界的绝对坐标。 |

DOM 版分别使用 `.division-line-layer` 和 `.division-digit-layer` 承载线条与数字；二者均为绝对定位层。

### 可视化命名图谱

不同竖式物件及其统一名称请从 Vite 服务访问 `/docs/vertical-division-elements.html`，或从主页面的“查看竖式物件命名图谱”入口打开。该文件复用正式竖式的视觉结果；同色高亮线框直接贴合目标物件，框右上角显示中文名称。桌面端目录与图谱左右并列，目录中的勾选框可显示或隐藏对应的全部高亮框。它仅作术语参考，不参与应用运行时渲染。

该页面右侧另有“除法器结果 JSON”面板：显示带中文字段说明的除法器输出，默认展开全部层级，并可展开或收起各个对象和步骤数组。

主生成器结果区底部也显示当前输入对应的原始除法器 JSON，输入或结果模式变化时同步更新，计算失败时清空。

## 2. 坐标与列对齐

- 页面使用绝对定位坐标系；数字与线条不得由普通文档流决定位置。
- 数字列宽为 `cw`（默认 `32px`，可设置范围 `28–56px`），行高为 `rh`（默认 `46px`，可设置范围 `36–64px`）；数字在各自单元格中水平、垂直居中。
- 除数位于左侧区域并右对齐；除数的每一位必须占用一个宽度为 `cw` 的完整数字方格，不能作为一个连续文本节点渲染。
- 除数最右一位的方格右边界必须与宽度为 `cw / 2` 的厂字弧线单元格左边界相接，之间不得保留空列或额外间距。
- 被除数第 `i` 位位于弧线右侧第 `i` 个数字列；商位依据其 `column` 与来源被除数位垂直对齐。
- 部分被除数和乘积均右对齐，最低位对齐到本轮 `dividendColumn` 列；减法线左端与部分被除数左端对齐，右端固定到数字区最右边界。
- 最终余数右对齐到扩展后被除数的最后一列，显示于所有实际减法步骤之后；小数模式补出的 `0` 也属于该对齐范围。
- 辅助网格启用时，必须覆盖除数区、弧线区、被除数字区和全部步骤行；除数区不得遗漏。
- 小数模式成功时，补出的被除数 `0` 继续占用右侧数字列并使用弱化颜色；商的小数点位于原被除数最后一列之后。
- 小数点渲染在原被除数最后一列与第一个补出 `0` 的数字列之间的边界上；小数点使用独立的窄节点视觉定位，不占用任何数字单元格，也不能改变补出 `0`、商位或后续步骤的列坐标。

## 3. 行结构

```text
Row 0：商（逐位对齐）
Row 1：除数、厂字弧线和被除数；顶部横线从弧线终点向右延伸
Row 2：首轮乘积；减法线贴在该行下边界（首轮部分被除数已在被除数行显示，不重复绘制）
后续步骤：当前部分被除数 → 乘积；减法线贴在乘积行下边界
最后一行：最终余数（包括 0）
```

- 首轮的 `current` 是被除数行中已取出的前缀；只绘制其乘积和减法线，不能在下方重复绘制该前缀。
- 商开始后的商位为 `0` 时，计算层仍保留完整步骤；默认只显示商数字，不绘制当前部分被除数、乘积或减法线。打开“显示试商为 0 的步骤”后，才绘制对应的 `当前部分被除数 − 0`、乘积 `0` 和减法线。整商为 `0` 的补记步骤遵循同一开关。
- 减法线是相邻内容行的边框，和厂字顶部横线一样不占用独立行；下一段部分被除数或最终余数紧接在边框下方。
- 竖式总高度、减法线起点与终点均按当前可见步骤重新计算。

## 4. 厂字弧线与横线

- `.division-svg` 与 `.division-dom` 分别使用独立的绝对定位画布；两者以同一 `VerticalDivisionRenderModel` 绘制命名的厂圆弧、厂横线、减法线、网格和数字。
- 两个渲染器必须在结果区并列、同时显示，并复用相同的坐标与计算结果，供直接比较。
- SVG 必须使用与页面相同的绝对坐标系，并以 `viewBox`、`width`、`height` 同步当前竖式范围。线条图形在数字图形之前插入，保持其位于数字底层；`div + CSS` 模式使用 `.division-line-layer` 和 `.division-digit-layer` 的相同层级关系。
- 厂字弧线必须在弧线单元格内**从左下角起笔、到右上角收笔**；右上终点与顶部横线左端连接。
- SVG 使用底部短横、右下圆角和右侧上收组成的路径，方向必须与 `div + CSS` 模式一致；`state.bracketBend` 仅改变圆角半径，不得平移端点。`div + CSS` 使用右边框、下边框和右下圆角，并按半个线宽补偿画布盒子，使弧线端点和 SVG 描边中心线对齐。
- 顶部横线延伸至数字区域最右边界，不得遮挡商或被除数；与厂弧线连接的一端使用平端，不能因线帽向弧线左侧或上方溢出形成十字。
- 厂字弧线、顶部横线、减法线和图例线共用 `3px` 笔画宽度；辅助网格保持独立的细虚线样式。

## 5. 辅助网格与状态

- 辅助网格默认关闭；打开后仅显示数字列和行边界虚线，不能影响实际坐标。
- `state` 包含 `cellWidth`、`rowHeight`、`fontSizeRatio`（默认 `0.82`，可设置范围 `0.60–0.95`）、`bracketBend`（默认 `1`，可设置范围 `0.50–1.50`）、`showGuideGrid`、`uniformSubtractionBars`（默认 `false`）、`showZeroQuotientSteps`（默认 `false`）、`resultMode`、`maxDecimalDigits`、`divisor` 与 `dividend`。
- 输入、方格宽度、行高、字号比例、弧线弯曲度、辅助网格或减法线等宽设置变化时，必须完整重新计算两套竖式。
- 输入区按“被除数 ÷ 除数”从左到右排列，两个输入框之间显示除号。
- 页面主布局在桌面端按横向排列：输入区位于左侧，结果渲染区位于右侧；页面最大宽度为 `1820px`，结果区约为输入区的两倍宽度，以同时展示两个渲染器。移动端回退为上下排列。样式设置始终包含在输入区内部。
- 样式控件不显示标题，也不提供展开/收起功能；控件始终直接显示在操作按钮下方。
- 样式控件在桌面端使用两列网格排列，四个滑杆占用两行；辅助网格与减法横线等宽开关占用下一行。窄屏时回退为单列。
- “减法横线等宽”开启时，所有可见减法线左端必须对齐到本题最靠左的减法线起点；右端仍固定到数字区最右边界。
- “显示试商为 0 的步骤”关闭时，排版层从 `computation.steps` 过滤 `quotientDigit = "0"` 的步骤，并按剩余可见步骤重新计算行号、减法线和总高度；开启时按原始步骤顺序全部绘制。
- 结果模式默认使用小数模式；操作区内的 radio-group 紧跟“生成竖式”和示例按钮，提供小数 / 余数模式切换，不属于样式设置内容。

## 6. 同步与验证

排版、线条或任一渲染器改变时，必须同步更新本文件，并至少执行 `npm run build`。涉及弧线时，还必须确认其视觉方向为左下到右上，且终点与顶部横线连接，并在 SVG 与 `div + CSS` 两种模式中保持一致。

## 7. 历史规则（可恢复）

### V13.0：零商步骤省略显示

V13.0 曾规定：商位为 `0` 时只显示商数字，不绘制当前部分被除数、乘积或减法线，也不额外占用步骤行。当前规则由渲染开关默认恢复该视觉行为，但零商步骤始终保留在计算数据中，供切换后完整展示。
