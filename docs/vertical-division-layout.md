# 小学除法竖式排版规则

> 版本：V10.0  
> 适用范围：`vertical-division-demo` 的坐标、DOM/CSS 渲染、线条和交互状态

本文件以 `deepseek_html_20261028_7a4ad6.html` 为规则来源，描述项目当前的 `div + CSS` 视觉实现。整数逐位长除法规则见 [`division-rules.md`](./division-rules.md)。

## 1. 坐标与列对齐

- 页面使用绝对定位坐标系；数字与线条不得由普通文档流决定位置。
- 数字列宽为 `cw`（默认 `44px`），行高为 `rh`（默认 `46px`）；数字在各自单元格中水平、垂直居中。
- 除数位于左侧区域并右对齐；除数的每一位必须占用一个宽度为 `cw` 的完整数字方格，不能作为一个连续文本节点渲染。
- 除数最右一位的方格右边界必须与宽度为 `cw / 2` 的厂字弧线单元格左边界相接，之间不得保留空列或额外间距。
- 被除数第 `i` 位位于弧线右侧第 `i` 个数字列；商位依据其 `pos` 与来源被除数位垂直对齐。
- 部分被除数和乘积均右对齐，最低位对齐到本轮 `pos` 列；减法线左端与部分被除数左端对齐，右端固定到数字区最右边界。
- 最终余数右对齐到扩展后被除数的最后一列，显示于所有实际减法步骤之后；小数模式补出的 `0` 也属于该对齐范围。
- 辅助网格启用时，必须覆盖除数区、弧线区、被除数字区和全部步骤行；除数区不得遗漏。
- 小数模式成功时，补出的被除数 `0` 继续占用右侧数字列并使用弱化颜色；商的小数点位于原被除数最后一列之后。
- 小数点渲染在原被除数最后一列与第一个补出 `0` 的数字列之间的边界上；小数点使用独立的窄节点视觉定位，不占用任何数字单元格，也不能改变补出 `0`、商位或后续步骤的列坐标。

## 2. 行结构

```text
Row 0：商（逐位对齐）
Row 1：除数、厂字弧线和被除数；顶部横线从弧线终点向右延伸
Row 2：首轮乘积；减法线贴在该行下边界（首轮部分被除数已在被除数行显示，不重复绘制）
后续步骤：当前部分被除数 → 乘积；减法线贴在乘积行下边界
最后一行：最终余数（包括 0）
```

- 首轮的 `current` 是被除数行中已取出的前缀；只绘制其乘积和减法线，不能在下方重复绘制该前缀。
- 商位为 `0` 的步骤只显示商数字，不绘制当前部分被除数、乘积或减法线，也不额外占用三行。
- 减法线是相邻内容行的边框，和厂字顶部横线一样不占用独立行；下一段部分被除数或最终余数紧接在边框下方。
- 竖式总高度、减法线起点与终点均按当前可见步骤重新计算。

## 3. 厂字弧线与横线

- 仅使用 `div + CSS` 绘制线条，不使用 SVG。
- `.math-lines` 为底层（`z-index: 1`），包含网格、厂字弧线、顶部横线和减法线；`.math-layer` 为数字层（`z-index: 2`）。
- 厂字弧线必须在弧线单元格内**从左下角起笔、到右上角收笔**；右上终点与顶部横线左端连接。
- 通过翻转后的 CSS 顶边/右边边框和圆角绘制弧线；`state.bend` 仅改变曲率，不得平移端点。
- 顶部横线延伸至数字区域最右边界，不得遮挡商或被除数。
- 厂字弧线、顶部横线、减法线和图例线共用 `3px` 笔画宽度；辅助网格保持独立的细虚线样式。

## 4. 辅助网格与状态

- 辅助网格默认关闭；打开后仅显示数字列和行边界虚线，不能影响实际坐标。
- `state` 包含 `cw`、`rh`、`fsRatio`、`bend`（默认 `1`）、`showGrid`、`resultMode`、`maxDecimalDigits`、`divisor` 与 `dividend`。
- 输入、方格宽度、行高、字号比例、弧线弯曲度或辅助网格变化时，必须完整重新计算并渲染。
- 输入区按“被除数 ÷ 除数”从左到右排列，两个输入框之间显示除号。
- 页面主布局在桌面端按横向排列：输入区位于左侧，结果渲染区位于右侧；移动端回退为上下排列。样式设置始终包含在输入区内部。
- 样式设置标题始终显示并承担展开/收起入口；收起时只保留标题行，展开时在标题下方显示样式控件，并通过 `aria-expanded` 与 `aria-controls` 反映状态。
- 结果模式默认使用小数模式；用户可以在输入框下方的操作区切换为余数模式，不属于样式设置内容。

## 5. 同步与验证

排版、线条或 DOM/CSS 渲染改变时，必须同步更新本文件，并至少执行 `npm run build`。涉及弧线时，还必须确认其视觉方向为左下到右上，且终点与顶部横线连接。
