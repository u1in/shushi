# 小学除法计算规则

> 版本：V10.0  
> 适用范围：`vertical-division-demo` 的整数输入校验、逐位长除法和渲染数据流

本文件以 `deepseek_html_20261028_7a4ad6.html` 为规则来源，保留项目既定的“字符串逐位运算、不使用大数类型”实现约束。竖式坐标与 CSS 线条见 [`vertical-division-layout.md`](./vertical-division-layout.md)。

## 1. 术语与入口约束

| 术语 | 代码名称 | 约束 |
| --- | --- | --- |
| 被除数 | `dividendDigits` / `D` | 非负整数 |
| 除数 | `divisorDigits` / `d` | 正整数 |
| 商 | `quotientText` / `q` | 非负整数 |
| 余数 | `remainder` / `r` | `0 <= r < d` |

- 只处理非负整数除以正整数；小数、负数、空值和其他格式必须报错，不得静默转换。
- 输入中的前导 `0` 在计算前移除；零规范化为字符串 `"0"`。
- 整段输入、当前部分被除数、乘积和余数都保存为数字字符串，不能转为 `Number`、`BigInt` 或其他大数类型。
- 单个字符数字可短暂转为 `Number`，仅用于逐位乘法进位、借位和比较。

## 2. 核心不变量

任意完整计算都必须满足：

```text
D = d × q + r
0 <= r < d
```

实现以字符串逐位完成比较、乘以一位数和减法；因此数字长度不受 JavaScript 安全整数范围限制。

## 3. 逐位长除法

从被除数最高位向最低位遍历，维护滚动余数 `remainder`：

```text
current   = remainder 右侧拼接 nextDigit，并移除前导 0
qd        = 使 divisor × qd <= current 的最大一位数（0..9）
product   = divisor × qd
remainder = current - product
```

- `qd` 通过从 `9` 向 `0` 的一位试商取得，`product` 和减法均为字符串逐位运算。
- 商尚未开始且 `qd = 0` 时，只更新余数，不写商位，也不记录竖式步骤。
- 商开始后，每轮都写入商位；中间与末尾的 `0` 都必须保留。
- 每一轮在 `steps` 中记录 `pos`、`partial/current`、`subtrahend/product`、`remainder` 与 `showSubtract`。当 `qd = 0` 时，`showSubtract` 为 `false`。

## 4. 规则明细

### R1 前导零不写

商的第一位不能为 `0`，除非整个商就是 `0`。例如 `102 ÷ 3` 中第一位 `1` 不够除时跳过，商从 `10 ÷ 3 = 3` 开始。

### R2 商位对齐且位数受限

每个商位对齐到产生该商位的被除数数字列；商位数不超过被除数位数。

### R3 余数范围

每轮计算后均有 `0 <= remainder < divisor`。若余数不小于除数，则试商或减法有误。

### R4 中间和末尾的零

只有前导零可省略。`1040 ÷ 5 = 208`、`60 ÷ 3 = 20`、`608 ÷ 2 = 304` 中的零都必须写在商内。

### R5 商位为零时不画减法

商已开始后，`qd = 0` 仍需写商位；但 `0 × divisor` 无意义，因此不画乘积、减法线或额外步骤行，直接继续落下一位。

### R6 被除数小于除数与零

- `D < d`：商为 `0`，余数为 `D`。
- `D = 0`：商为 `0`，余数为 `0`。
- `d = 1`：商等于被除数，余数为 `0`。

### R7 余数模式与小数模式

- 余数模式在被除数最后一位处理完毕时结束，显示整数商和余数。
- 小数模式从整数余数右侧逐位补 `0`，继续使用相同的字符串试商、乘法和减法规则。
- 若余数变为 `0`，显示有限小数；补出的 `0` 显示在被除数行并使用弱化颜色。
- 若余数重复（循环小数）或计算达到 `state.maxDecimalDigits`（默认 `24`）仍未结束，自动回退至余数模式，显示原整数商和余数，不显示截断小数。

### R8 终止条件

余数模式在被除数最后一位处理完毕时结束；小数模式在余数为 `0`、检测到循环或达到安全位数上限时结束。最终有效余数无论是否为 `0` 都显示在竖式最底部。
